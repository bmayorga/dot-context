# Minimal Project Example

> **How to use this example:** This demonstrates the smallest useful context setup without a named product, stack, or environment. Start with AGENTS.md, then .context/README.md and STATUS.md. Adapt these hypothetical facts to verified project state; this is documentation, not application code.

## Files

- [AGENTS.md](AGENTS.md): agent instructions.
- [.context/README.md](.context/README.md): discovery and maintenance.
- [.context/STATUS.md](.context/STATUS.md): present state and priorities.

No specialized reference or plan is needed while the current facts fit in a short status.
Add one only when its subject needs a separate owner. The
[growing example](../growing/README.md) shows that next step.

.context/README.md includes all six design recommendations enabled as template defaults; the
developer may disable individual preferences without adding a context document.
The optional Development and Release Workflow is disabled here; the template offers it
enabled, but the developer chooses whether to adopt it and confirms branch configuration.
